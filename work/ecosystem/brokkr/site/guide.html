Project guide

Engineering harnesses and deterministic verification with retained evidence.

Requirements

Node.js 25 or newer, pnpm and Git.

Build and run

pnpm install --frozen-lockfile
pnpm build
node apps/cli/dist/bin.js --help

Run these commands from the repository root. Read the complete README for authentication, configuration, service ports and operating limits.
