# Gate: spec §18.5 end to end scenarios

Recorded 2026-10-14 on macOS arm64, Node v25.9.0, pnpm 12.11.2, branch `task/B3b` (main at `8869011` plus B3b). Every scenario below passed in the uncached gate `TURBO_FORCE=true pnpm check` (27/27 turbo test tasks, 647 tests at fix round 1) and in a focused verbose run of the named files.
