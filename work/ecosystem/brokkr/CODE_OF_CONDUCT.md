# Code of conduct

Brokkr is a free, Apache-2.0 project. Everyone who takes part (in code, reviews, issues or discussion) agrees to the following.

## Expected behaviour

- Be respectful and assume good intent. Critique code and ideas, not people.
- Be precise and evidence based: link the log, the test or the line of code.
- Welcome newcomers. Explain project conventions instead of pointing at them.
- Accept a maintainer's decision on scope gracefully; you can reopen the question with new evidence.

## Unacceptable behaviour

- Harassment, insults, slurs or sexualised language and imagery.
- Personal or political attacks, trolling, deliberate disruption.
- Publishing anyone's private information without permission.
- Pressuring someone to disclose a vulnerability publicly before it is fixed.

## Enforcement

Report problems privately to the maintainers (see `SECURITY.md` for the contact used for private reports). Maintainers review every report, keep the reporter's identity confidential, and may warn, temporarily ban or permanently ban a participant. Decisions and their reasons are recorded.

This code applies in every project space and when someone represents the project elsewhere.
