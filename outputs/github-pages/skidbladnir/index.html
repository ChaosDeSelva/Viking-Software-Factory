What you can do.

Explore without cloud resources

Create simulated workers and exercise lifecycle controls in a local dashboard with persistent history.

Manage an owned AWS fleet

Configure approved images, capacity limits, resource ownership and independent expiration for disposable EC2 workers.

Connect work to compute

Use SSM commands, bounded artifacts and optional REST or MCP worker controls. Mimir can place supported missions on approved workers.

Where it fits.

Skidbladnir owns disposable worker infrastructure. Mimir owns agent execution placed on that infrastructure. The local simulator is the default and does not launch real virtual machines.

Start on your own machine.

Node.js 24 or newer and npm. The default simulator needs no AWS account.

Clone Skidbladnir and run these commands from its root directory.

npm ci
npm run build
npm test
npm start

Read the full project guide for configuration and service connections.
