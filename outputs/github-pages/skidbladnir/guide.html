Project guide

Disposable development workers, local simulation and an optional owned AWS fleet.

Requirements

Node.js 24 or newer and npm. The default simulator needs no AWS account.

Build and run

npm ci
npm run build
npm test
npm start

Run these commands from the repository root. Read the complete README for authentication, configuration, service ports and operating limits.
