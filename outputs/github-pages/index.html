What you can do.

Plan with Sindri

Capture the request, review a specification and approve a task plan with dependencies and acceptance criteria.

Execute and verify

Mimir runs the crews in isolated worktrees. Brokkr runs configured engineering checks and retains the evidence.

Review in Heimdall

Inspect progress, blockers and delivery gates. Use Hulder for editing and add Skidbladnir workers when you need compute.

Where it fits.

The factory combines independent local tools. It does not require GitHub to run, and publishing code is separate from accepting a local delivery. Bifrost connects agents to Hulder; Skidbladnir manages optional disposable compute.

Start on your Mac.

Download Mac setup

Extract the ZIP and move Viking Factory.app to Applications. Open it, select optional components and choose Install bundle. Select factory-manifest.json from the extracted bundle directory. Run Health check, sign into your agent tools, then start the factory. Node and npm are included. Git and agent tools remain separate prerequisites. Installation creates no cloud resources.

Build from source instead

Node.js 25 or newer, pnpm 12.11.2, Git and installed agent CLIs. Agent login is separate.

Clone Viking-Software-Factory and run these commands from its root directory.

./build.sh
node outputs/local-factory/factory.mjs
