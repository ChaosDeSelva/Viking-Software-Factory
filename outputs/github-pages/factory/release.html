v0.2.0 release notes

Native Mac companion and signed runtime bundles for Apple silicon, macOS 13 or newer.

Download Mac setup

Extract the ZIP and move Viking Factory.app to Applications. Open it, select optional components and choose Install bundle. Select factory-manifest.json from the extracted bundle directory. Run Health check, sign into your agent tools, then start the factory. Node and npm are included. Git and agent tools remain separate prerequisites. Installation creates no cloud resources.

Tested scope

5,151 package tests passed in the October 17 audit. A real Codex counter acceptance run passed all six delivery gates on October 18. Fixture acceptance and real agent acceptance are distinguished in the audit report. The v0.2.0 Mac companion passed CI, notarization and a live GitHub update with signature verification and service restart on a disposable installation.

These are recorded acceptance results, not a new test run for every website update.

Acceptance limits

Experimental v0.2.0 Mac preview. Codex and Claude Code are the primary local agent paths. Other vendor profiles and terminal bridges without authenticated acceptance remain experimental. Manual screen reader acceptance remains pending. Remote and AWS acceptance cover specific disposable environments, not every host or image.

Source publication

Source is available on GitHub. Preserve project and dependency license notices when redistributing. The companion and bundled Hulder app are Developer ID signed, notarized and stapled. Manual accessibility, login registration and a separate clean Mac acceptance remain pending.
