v0.2.0 release notes

Updated source preview for the coordinated Viking Factory 0.3.0 release. Internal package versions may differ from the source tag.

Install the coordinated Mac preview

Download Viking Factory 0.3.0

The setup includes Mimir, the other factory services and the native companion. Requires Apple silicon and macOS 13.5 or later. Node and npm are bundled; Git, agent tools and their authentication are separate prerequisites.

This release

This preview includes the refreshed runtime and dependencies, plus database-lock recovery that preserves live reclaimers and handles malformed process identifiers. Production build and type checks passed. Component tests recorded 4,953 unique passes and five existing optional skips; four retention checks passed on retry with a 60-second timeout. Final database-lock and refreshed Brokkr-verifier regression checks also passed. See the release record for details.

Historical acceptance evidence

427 server tests passed on October 18, including local sockets and tmux. The wider October 17 factory run passed 5,151 tests across 34 package suites.

These earlier results are retained as historical evidence; they do not describe new runs for this preview.

Acceptance limits

Experimental v0.2.0 source preview. Codex and Claude Code are the primary local harnesses. Other agent profiles and Zellij, cmux and Orca bridges remain experimental without authenticated live acceptance. Local agents run with your user privileges. Manual accessibility acceptance remains pending.

Source publication

Source is available on GitHub. Preserve project and dependency license notices when redistributing. The coordinated Mac installer supplies the prebuilt runtime; this repository release provides the component source.
