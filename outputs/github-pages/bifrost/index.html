Bring editor context to your agents.

Get startedProject guideView source

What you can do.

Share the current workspace

Expose editor context, selection, diagnostics, Saga notes and clippings through MCP.

Keep transport local

Relay standard input and output to Hulder through an explicit Unix socket with bounded requests and project path checks.

Maintain one bridge implementation

Build the relay independently. Hulder embeds a verified source snapshot of the core and native adapter.

Where it fits.

Bifrost connects an MCP client to a running Hulder workspace. It is not a hosted service or a general cloud worker manager. The native adapter builds inside Hulder.

Start on your own machine.

Rust 1.98.1 and Python 3. The native adapter builds within Hulder.

Clone Bifrost and run these commands from its root directory.

cargo build --locked
cargo test --locked
python3 -m unittest discover -s tests

Read the full project guide for configuration and service connections.

What we have verified

Clear evidence. Explicit limits.

34 extraction checks passed: 16 standalone tests, 16 native adapter tests and two snapshot checks. Linux CI is configured but was not run locally.

Experimental v0.1.0 source release. The standalone transport supports macOS and Linux; Windows transport is not implemented. Native editor integration requires Hulder. Socket ownership checks are not protection against a hostile process running as the same user. Client compatibility requires testing with that client.
