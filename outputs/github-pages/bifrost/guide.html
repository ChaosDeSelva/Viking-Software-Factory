Project guide

A local MCP relay connecting terminal agents to Hulder through a Unix socket.

Requirements

Rust 1.98.1 and Python 3. The native adapter builds within Hulder.

Build and run

cargo build --locked
cargo test --locked
python3 -m unittest discover -s tests

Run these commands from the repository root. Read the complete README for authentication, configuration, service ports and operating limits.
