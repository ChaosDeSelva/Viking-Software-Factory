Bifrost setup guide

A local MCP relay connecting terminal agents to Hulder through a Unix socket.

Before you begin

Bifrost connects an MCP client to a running Hulder workspace. It is not a hosted service or a general cloud worker manager. The native adapter builds inside Hulder.

Requirements

Rust 1.98.1 and Python 3. The native adapter builds within Hulder.

Get the source

git clone https://github.com/ChaosDeSelva/Bifrost.git
cd Bifrost

Build and run

cargo build --locked
cargo test --locked
python3 -m unittest discover -s tests

Run these commands from the repository root. Keep local state and credentials outside version control.

Complete READMERelease notes

Your first session

  1. Build the relay, then start Hulder and open the project you want the agent to work on.
  2. Use hulder mcp for the integrated command, or run the standalone binary with the actual Hulder socket path from your configuration directory.
  3. Configure your MCP client with the executable and socket argument. Run it from a directory belonging to an open Hulder project.
  4. Inspect the exposed tool catalog before granting access. Some tools can change project content; the bridge is intended for a trusted local session.

Operating boundaries

The standalone transport supports macOS and Linux; Windows transport is not implemented. Native editor integration requires Hulder. Socket ownership checks are not protection against a hostile process running as the same user. Client compatibility requires testing with that client.
