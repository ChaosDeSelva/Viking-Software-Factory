v0.2.0 release notes

Signed and notarized standalone CLI preview for Apple silicon. Includes the rustix 1.1.6 dependency fix. The source package version remains 0.1.0; the distribution release is 0.2.0.

Download the Mac preview

Download Bifrost 0.2.0 for Mac

Extract the signed, notarized CLI for Apple silicon. Start Hulder, open your project, and run the relay from that project with its actual socket path.

./bifrost --socket /absolute/path/to/hulder.sock

For the coordinated tools and native companion, download Viking Factory 0.3.0 setup (Apple silicon, macOS 13.5 or later).

Tested scope

The November 18 release checks passed 16 Rust tests and two Python snapshot tests. The embedded Hulder snapshot matched Bifrost. The signed CLI passed Apple notarization and online notarization verification; its Rust dependency audit reported no vulnerabilities or warnings.

The earlier extraction audit passed 34 checks: 16 standalone tests, 16 native adapter tests and two snapshot checks. Those native adapter results are historical; Linux CI was not run locally for this release.

The current release checks and historical extraction audit are reported separately.

Acceptance limits

Experimental v0.2.0 preview. The standalone transport supports macOS and Linux; Windows transport is not implemented. Native editor integration requires Hulder. Socket ownership checks are not protection against a hostile process running as the same user. Client compatibility requires testing with that client.

Source publication

Source is available on GitHub. Preserve project and dependency license notices when redistributing. The ZIP includes the signed CLI, source provenance, GPL license and dependency notices. The CLI is notarized; plain executables and ZIP files do not carry stapled tickets.
