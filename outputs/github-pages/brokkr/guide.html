Brokkr setup guide

Engineering harnesses and deterministic verification with retained evidence.

Before you begin

Brokkr is a standalone CLI and SDK for engineering harnesses and verification. It does not schedule agents. Mimir and Sindri consume its results without replacing its verdict.

Requirements

Node.js 25 or newer, pnpm and Git.

Get the source

git clone https://github.com/ChaosDeSelva/Brokkr.git
cd Brokkr

Build and run

pnpm install --frozen-lockfile
pnpm build
node apps/cli/dist/bin.js --help

Run these commands from the repository root. Keep local state and credentials outside version control.

Complete READMERelease notes

Your first session

  1. Build the CLI and inspect its help. Choose a disposable repository for your first verification run.
  2. Run init with the target repository to select harnesses and create its configuration and lock.
  3. Run verify against that repository and inspect the report. A missing prerequisite can produce incomplete or blocked rather than passed.
  4. For agent worktrees, use the documented untrusted workspace mode with trusted configuration and lock files outside the worktree.

Operating boundaries

Checks execute locally and are not an operating system sandbox. A verification report covers only the selected checks and the evaluated workspace. Review harness trust and command policy before running unfamiliar code.
