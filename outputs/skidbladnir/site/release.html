v0.2.0 release notes

Updated source preview for the coordinated Viking Factory 0.3.0 release. Internal package versions may differ from the source tag.

Install the coordinated Mac preview

Download Viking Factory 0.3.0

The setup includes Skidbladnir, the other factory services and the native companion. Requires Apple silicon and macOS 13.5 or later. Node and npm are bundled; Git, agent tools and their authentication are separate prerequisites.

This release

Production builds, 80 unit tests, type checks, lint, and browser checks of the simulator and AWS fixtures passed. The browser checks used fixtures and made no cloud calls. See the release record for details.

Historical acceptance evidence

20 local tests and isolated simulator and AWS fixture browser checks passed. Earlier disposable AWS acceptance is documented separately; it does not establish compatibility with every image or account.

These earlier results are retained as historical evidence; they do not describe new runs for this preview.

Acceptance limits

Experimental v0.2.0 source preview. Local simulation expiration only runs while the API is active and reconciles afterward. AWS expiration is configured independently. SSM reconnect starts a fresh shell; artifacts and mission envelopes are bounded. New images and account configurations need their own acceptance run.

Source is available on GitHub. Preserve project and dependency license notices when redistributing. The coordinated Mac installer supplies the prebuilt runtime; this repository release provides the component source.
