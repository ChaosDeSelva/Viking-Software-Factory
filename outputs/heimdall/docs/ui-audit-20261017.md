# Heimdall UI audit, October 17, 2026

Scope: the local Heimdall dashboard, shared components, mission inspection, overview data selection, and responsive navigation. This is not a certification of the entire factory or every provider integration.

## Findings resolved

1. Overview progress counted tasks from every mission beneath a single mission heading. A mission selector now scopes the progress and unfinished task list to the same mission. Selecting an older live demo correctly changes six of six to four of six.
2. Completed missions offered invalid lifecycle commands. Controls now match Mimir's allowed state transitions and are disabled when the record is missing or a source is offline. Server authorization and state validation remain authoritative.
3. Mission headings exposed generated plan identifiers as their primary title. The inspector now resolves the specification title, with the original mission identifier and source record still available.
4. Active crew counts depended on a crew configuration status. They now reflect active tasks or agents assigned to each crew.
5. Queued tasks could produce a completed headline. Completion language now requires all tasks to be complete.
6. Shared record rows had conflicting divider, margin and hover geometry. Rows now use consistent padding and gaps. Narrow screens place long titles above badges, preserving readable width.
7. Inspector action groups now share widths, spacing and wrapping. Mission summaries have inset hover surfaces and consistent badge dimensions.
8. Navigation retained the previous screen's scroll position. Changing screens now starts at the top.
9. Scroll observers were recreated when children rendered. A stable observer now tracks child replacement and cleans up on unmount.

## Validation

TypeScript and production Vite build passed. All 15 Node regression tests passed, including two new mission control tests. Existing tests cover authentication, command allowlisting, replay, source failures and persistence.

Live browser checks covered all ten navigation screens at 390 pixels with no document overflow. Verified mission selection changes task progress, completed mission controls are disabled, inspector headings are readable, horizontal pipeline controls update their directional hint, and navigation returns to the top. Checked overview in both themes and restored dark mode.

## Limits

No complete accessibility certification or exhaustive interaction coverage is claimed. The live demo still contains older failed tasks and delivery review blockers; these are source data and are intentionally visible. This UI audit does not resolve planning dependencies, review evidence ingestion, or provider account limits. Prepared publication copies and release archives were not refreshed in this pass.

## Project management and second layout pass

Added a Projects screen with repository search, active and archived views, archive confirmation, restore and project navigation. Archived identifiers are validated and persisted in Heimdall preferences. This is a presentation archive, not a Mimir or Sindri lifecycle transition. It does not terminate work, delete files or remove evidence. Factory service health and unscoped operational alerts remain visible. Archived projects are excluded from active project selection, task views and new work project choices.

Live acceptance archived the disposable counter demo, reloaded the page, verified zero active projects, then restored it. The demo is left active. Two new regression tests cover persistence, restore and malformed identifiers. The full Node suite now passes 17 tests.

Connections has separate Services, Access, Display and Audit history sections. Audit history uses eight entries per page, notifications use ten, activity uses twelve, and crews use six. Pipeline columns scroll independently rather than stretching every column to the height of the longest stage. Filtered stage counts and empty states reflect the search.

Fixed supervisor registration alignment by giving labels and their inputs separate alignment from the adjacent action. Both fields and the action measure 44 pixels high and share the same bottom coordinate. Fixed verification headers that forced tall badges into a fixed height button. New work cards use consistent vertical gaps without stretching the shorter form. Removed ineffective search controls. Mobile navigation now collapses to a 76 pixel header with an explicit Menu control.

Browser checks visited all eleven screens at 390 pixels and desktop widths; no document overflow was found. Desktop light theme checks also passed on all eleven screens, then dark mode was restored. Verified archive confirmation, reload persistence, restore, activity pagination, audit pagination, mission selection and mobile menu navigation. Screenshots are in outputs/heimdall-ui-review/20261017 relative to the workspace root.

The idle factory was restarted to load preference validation. The local browser was signed back in and operator access and Sindri pairing restored. No new builds or provider work were launched. This pass does not claim exhaustive behavior testing of every destructive or external control, nor does it resolve the delivery gate issues documented above.
