# Architecture and security

`apps/server/connectors.mjs` is the only upstream access layer. It accepts configured loopback origins, authenticates to upstream APIs, reconnects independent SSE streams, and refreshes snapshots. `storage.mjs` owns only Heimdall cursors, cached events, idempotency receipts, operator audit entries, notification read state and UI preferences. `commands.mjs` allowlists supported actions. There is no generic API proxy and no shell execution endpoint.

The HTTP server binds to 127.0.0.1. Host validation prevents arbitrary rebinding names. Same origin checks, a required custom request header, and HttpOnly SameSite=Strict cookies protect browser command requests. Login and operator code attempts are throttled. Sessions expire after 12 hours; approval secrets stay in process memory. The browser receives neither source bearer tokens nor Sindri approval secrets. Known credentials and credential shaped fields are redacted from display/cache payloads. Upstream services remain responsible for redacting arbitrary secrets inside their own logs; pattern matching is not proof that all possible secrets are absent.

Operator commands require an unlocked session, an allowlisted action, a resource ID, an idempotency key and a reason. Requested and confirmed/failed outcomes are audited locally. Upstream idempotency headers are forwarded. A pending receipt is written before dispatch, so a process crash cannot silently repeat a request with the same key. An uncertain outcome must be inspected at the source before a new attempt. Authorization is checked again before replaying any receipt.

Mimir execution approvals that belong to a Sindri execution are routed through Sindri's approval endpoint. Sindri's additional human factor is retained. If Sindri is disconnected and ownership cannot be confirmed, the approval is refused. Mimir only use relies on Heimdall's operator unlock plus Mimir's own token/policy checks.

Artifact content is fetched through the public Mimir artifact API and verified against the declared SHA-256 hash. Only safe raster image formats are embedded. HTML, SVG and logs are displayed as text, never executed. React escapes source strings; content security policy prohibits third party scripts, frames and external connections.

Snapshot refresh is all or nothing for each source. Failed reads retain the previous source snapshot with a disconnected flag; empty successful snapshots replace old records. Per execution event streams are closed when the corresponding execution disappears. SSE consumers that exceed the local output buffer are disconnected and receive a fresh snapshot on reconnection. The browser's snapshot stream is not a second source event log.

State directory permissions default to 0700 and the SQLite file to 0600. Stop Heimdall before backing up its state. Credentials and the real factory databases are not included in a source archive. Connection changes are authenticated from the UI and persisted in a mode-0600 file. Reconfiguration replaces the connector, clears that source’s cached events/cursors and invalidates Sindri pairing. Credentials are omitted from exported configuration. Preferences and notification state belong only to Heimdall.
