v0.2.0 release notes

Updated source preview for the coordinated Viking Factory 0.3.0 release. Internal package versions may differ from the source tag.

Install the coordinated Mac preview

Download Viking Factory 0.3.0

The setup includes Heimdall, the other factory services and the native companion. Requires Apple silicon and macOS 13.5 or later. Node and npm are bundled; Git, agent tools and their authentication are separate prerequisites.

This release

Production builds, 258 unit tests, and the isolated browser workflow checks passed. See the release record for details.

Historical acceptance evidence

51 Node tests passed. Automated accessibility covered eleven screens, both themes and three viewport sizes. Stress checks covered 25,000 events and three reconnect cycles.

These earlier results are retained as historical evidence; they do not describe new runs for this preview.

Acceptance limits

Experimental v0.2.0 source preview. This is a local operator interface, not a public remote control service. Automated accessibility checks do not replace manual screen reader acceptance, which remains pending. Agent compatibility follows the connected runtime’s support limits.

Source publication

Source is available on GitHub. Preserve project and dependency license notices when redistributing. The coordinated Mac installer supplies the prebuilt runtime; this repository release provides the component source.
