Heimdall setup guide

A local operator dashboard for projects, pipelines, agents and delivery.

Before you begin

Heimdall is the operator interface. Mimir remains the source of execution state; Sindri owns planning and delivery. Heimdall connects through authenticated APIs and event streams rather than editing their databases.

Requirements

Node.js 24 or newer and pnpm. Connect an existing local Mimir service after startup.

Get the source

git clone https://github.com/ChaosDeSelva/Heimdall.git
cd Heimdall

Build and run

pnpm install --frozen-lockfile
pnpm build
pnpm test
pnpm start

Run these commands from the repository root. Keep local state and credentials outside version control.

Complete READMERelease notes

Your first session

  1. Build and start Heimdall, then open http://127.0.0.1:4320. Use the access token printed in the terminal to sign in.
  2. Open Connections and unlock operator controls. Enter the loopback URL and token for Mimir, then test and save the connection.
  3. Connect Sindri when you want planning and delivery controls. Pair its separate approval session before taking approval actions.
  4. Create a small project or inspect an existing mission. Open task details, review artifacts and follow the source confirmed result of each control.

Operating boundaries

This is a local operator interface, not a public remote control service. Automated accessibility checks do not replace manual screen reader acceptance, which remains pending. Agent compatibility follows the connected runtime’s support limits.
