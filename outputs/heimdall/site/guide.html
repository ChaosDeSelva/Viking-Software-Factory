Project guide

A local operator dashboard for projects, pipelines, agents and delivery.

Requirements

Node.js 24 or newer and pnpm. Connect an existing local Mimir service after startup.

Build and run

pnpm install --frozen-lockfile
pnpm build
pnpm test
pnpm start

Run these commands from the repository root. Read the complete README for authentication, configuration, service ports and operating limits.
