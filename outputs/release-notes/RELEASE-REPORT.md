# Local release candidate

The current implementation evidence and explicit limits are recorded in
[Code status](CODE-STATUS.md) and [Factory implementation and acceptance](PARITY-REPORT.md).

These are development artifacts, not a public release. The native Hulder bundle uses
a local signature and has not been notarized. GitHub Pages sites are prepared locally.
No repository was published or made public during this work.

Source archives retain upstream license notices and include working changes.
Private runtime data and credentials are excluded. The source scan checks selected
credential patterns; it is not a comprehensive security audit.

The live exe.dev test used a dedicated synthetic workspace. No personal repository
or vendor credentials were uploaded. The dedicated VM was deleted after preserving the completed authenticated Codex acceptance evidence locally. A subsequent inventory confirmed its absence.
