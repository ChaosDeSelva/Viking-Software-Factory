# Security

Use the supported targets and release boundaries in the project documentation. Factory services are local operator tools with authenticated execution controls; do not expose their APIs directly to the internet.

Enable private vulnerability reporting when creating the GitHub repositories. Do not publish credentials or private source in issue reports. Keep runtime state, agent credentials and cloud profiles outside source control. Each project includes its own security guidance.

Hulder source supports Apple silicon macOS. Its inherited server deployment tools and other operating systems are not cleared release targets. See Hulder SECURITY.md for the dependency gate and documented maintenance notices.
